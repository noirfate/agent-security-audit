# 护栏、日志与评测有效性

读取护栏调用位置、判定规则、失败策略、日志字段、评测输入和结果消费代码。列出控制意图保护的主体、资源、动作与阶段，再核对实际执行位置。

沿入口、工具调用、结果输出、重试、恢复和异常路径检查控制覆盖。检查超时、解析失败、服务不可用是否被当作通过；审计工具也不能把空结果或任务失败当安全结论。

评测记录核对真实目标、版本、样本来源、成功判据、运行环境和观测方式。模拟响应与真实运行分开，模型自述与工具 trace/副作用分开；Canary 原样回显不自动证明敏感数据外泄。

反证重点：控制是否覆盖对应失效条件、拒绝后是否仍执行副作用、日志是否足以关联同一主体和请求、评测失败与未执行是否单列。一次成功阻断只支持该版本和条件，不能推广到全部风险。

有效控制写入 controls，关联不成立检查中的具体反证，记录 scope、limitations、rationale 与 retest。部分覆盖用 limited，材料缺失用 unknown；不能把不适用检查当作控制有效证明。

复核报告同时保留失败、证据不足、未检查和成功阻断的记录；覆盖以对象、边界和适用检查为依据，不以固定 payload 数量或简单扣分替代。
