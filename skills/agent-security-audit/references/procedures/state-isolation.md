# 状态隔离、持久化与恢复

清点会话、长期记忆、知识库、索引、缓存、检查点和持久存储。读取实际键结构、访问过滤、写入者、更新与删除路径，以及恢复和迁移过程。

分别追踪读、写、检索、删除和恢复。比较主体/租户字段从认证上下文到最终查询是否保持；检查写入内容会不会在下一次会话成为高信任指令。缓存命中与检查点恢复也要经过等价的授权和来源检查。

成立证据应证明越过真实隔离边界、未经授权改变后续状态，或已撤销/删除数据可经恢复路径重新生效。共享存储服务不自动意味着共享数据权限。

反证重点：复合命名空间、强制查询过滤、独立存储凭据、读写权限分离、删除传播和恢复版本校验。仅保存 tenant_id 不能证明查询时使用它；仅出现全局字典也不能忽略调用者隔离。

记录查过的所有同类访问路径，特别是管理接口、批处理、调试导出和后台任务。测试账号/示例数据要分析是否进入真实路径，不按文件名直接排除。

动态验证应使用两个受控身份和独立 canary，记录写入、读取、会话切换及清理条件。没有真实跨身份观测时保留静态结论或证据不足。
