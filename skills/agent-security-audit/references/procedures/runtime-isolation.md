# 执行、工作区与网络隔离

读取进程启动、容器/沙箱配置、挂载、环境注入、工作目录、浏览器账号环境、网络出口和代理设置。记录隔离单位究竟是宿主、工作负载、租户还是单次任务。

从不可信参数追到解释器、文件访问和网络请求。核对路径规范化、符号链接、归档展开、URL 解析、DNS、重定向及代理的执行顺序；确认检查与使用的是同一目标。

成立证据需要说明获授权执行范围及实际逃出的资源边界。框架设计为执行代码不等于 RCE 漏洞，访问内网也不自动构成 SSRF；关键是独立攻击者能否驱动超范围访问。

反证重点：最终运行身份、实际启用的只读挂载、权限能力、网络策略、凭据范围与失败回退。容器存在、厂商支持某安全功能或示例配置均不能证明线上启用。

环境不可见时，将平台承诺、提供的配置和不可见实现分开记录。二进制与驱动不能仅凭版本关键词推断可利用；已有漏洞公告也需核对产品、版本和调用条件。

静态审计不启动目标，不安装依赖或运行其测试。动态验证另行限定端点和动作；本 skill 的 HTTP 工具不提供沙箱逃逸验证或 Shell 执行。
