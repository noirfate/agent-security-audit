# 接口、解析与渲染边界

取得 API 路由、消息入口、上传处理、解析器、模板、Markdown/Mermaid/HTML 渲染器、会话中间件和浏览器展示配置。区分服务端解析、浏览器解释与导出文件使用环境。

追踪输入内容经过解码、净化、模板插值和渲染后的最终解释位置。检查渲染期间是否加载外部资源，以及浏览器凭据、服务端网络权限和文件权限；同时核对会话绑定与普通 API 旁路。

XSS 需要独立攻击者控制内容、危险语法到达可执行环境以及受害者上下文；渲染 SSRF 需要受控资源地址到达具有相应网络权限的请求路径。仅生成可打开的 HTML 或解析图表不充分。

反证重点：最终编码上下文、净化发生的顺序、禁用脚本/外部资源的有效配置、内容来源、受影响用户与域隔离。纯用户自创内容与自动混入第三方数据应分别处理。

检查导出、预览、附件与错误页面是否使用不同渲染路径。记录对应依赖和配置版本，不能把一个路径的净化推广到全部展示面。

动态验证需要受控页面或观察记录；没有真实渲染证据时只报告静态路径和可见控制，不能声称浏览器已执行载荷。
